# Бронювання дат — запуск і передача

Бекенд — Google Apps Script у Google-таблиці студії. Безкоштовно, не «засинає», адмінка — сама таблиця й Google Календар.

```
Сайт ──GET ?action=availability──▶ Apps Script ──▶ вільні дати (без персональних даних)
Сайт ──POST заявка──────────────▶ Apps Script ──▶ рядок у «Заявках» + подія в Календарі
                                                 └─▶ лист студії, Telegram, лист клієнту
```

## Запуск (≈15 хв, у Google-акаунті студії)

1. Увійдіть в **окремий Google-акаунт Nectar** (не особистий — його потім передаєте студії).
2. Створіть таблицю: [sheets.new](https://sheets.new) → назва «Nectar — бронювання».
3. **Розширення → Apps Script.** Видаліть вміст `Code.gs` і вставте код із `backend/Code.gs`.
4. ⚙️ **Налаштування проєкту** → увімкніть «Показувати файл маніфесту appsscript.json» → замініть його вміст на `backend/appsscript.json`.
5. Оберіть функцію **`setup`** → **▶ Виконати** → дозвольте доступи (таблиця, календар, пошта, зовнішні запити).
   *Google покаже «Додаток не перевірено» — це ваш власний скрипт: «Додатково → Перейти до проєкту».*
6. **Розгорнути → Нове розгортання → Тип: Веб-застосунок.** Виконувати як: **Я**. Доступ: **Усі**. → Розгорнути. Скопіюйте адресу `https://script.google.com/macros/s/…/exec`.
7. Перевірте: відкрийте `…/exec?action=availability` — має бути JSON із `"ok":true`.
8. На сайті: `assets/js/data.js` → `booking.endpoint: "…/exec"` → commit і push. Банер «заявка відкриється в Direct» зникне, календар покаже реальні дати.
9. Зробіть тестову заявку на сайті, перевірте рядок у таблиці, подію в календарі й лист. Потім поставте їй статус «скасована».

### Telegram (необов'язково)
1. У Telegram напишіть [@BotFather](https://t.me/BotFather) → `/newbot` → отримаєте токен.
2. Створіть групу студії, додайте туди бота, напишіть у групу будь-що.
3. Відкрийте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` → знайдіть `"chat":{"id":-100…}`.
4. Впишіть токен і chat id у лист «Налаштування».

### Після змін коду
**Розгорнути → Керувати розгортаннями → ✏️ → Версія: нова → Розгорнути.** Адреса лишається тією самою.

## Щоденна робота студії
- Нова заявка: жовта подія в календарі, лист/Telegram. Дата тримається 48 год (лист «Налаштування»).
- Подзвоніть клієнту → змініть статус: **підтверджена → передоплата → виконано**. Подія змінює колір сама.
- **скасована / прострочена** звільняють дату на сайті й прибирають подію з календаря.
- Ємність: лист «Ресурси» (слоти й місця в слоті). Вихідні: «Закриті дати». Сезон і запас днів: «Налаштування».
- Назви слотів — одним словом (ранок, день, вечір): за ними рахується зайнятість.

## Передача студії
| Що | Як передати |
|---|---|
| Google-акаунт Nectar (таблиця, скрипт, календар) | Передати логін, студія змінює пароль і номер для відновлення, вмикає 2FA. Скрипт і розгортання лишаються робочими. |
| Сайт (GitHub) | Settings → Transfer ownership на GitHub-акаунт/організацію студії. Адреса `*.github.io` зміниться — краще одразу підключити власний домен (напр. nectar…ua), тоді адреса не зміниться. |
| Telegram-бот | @BotFather → `/mybots` → Transfer ownership. |
| Реквізити ФОП | Вписати в `privacy.html` і `assets/js/data.js → seller`. |

## Безпека й дані
- GET повертає тільки кількість вільних місць — жодних імен чи телефонів.
- POST: перевірка полів, пастка для ботів (`website`), ≤3 заявки з номера на годину, блокування одночасного запису (LockService) — двох бронювань одного слоту не буде.
- Текст із форми очищується, щоб не виконувався як формула в таблиці.
- Персональні дані — лише в акаунті студії. Видаляйте рядки старші 12 місяців (так написано в політиці конфіденційності).
